# KLY - Klyro Programming Language

Klyro (KLY) is an experimental programming language created to explore how programming languages work.

This project is being built from scratch in C++, starting with a lexer and parser and eventually growing into a fully functional interpreter.

Project Status ; 
klyro is currently a work in progress. Features are being implemented incrementally, and the language synntax may change as the project evolves.
